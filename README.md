# Визуализатор графа зависимостей пакетов

Учебный проект по дисциплине «Конфигурационное управление», практика 2,
вариант 4. Консольное приложение на Python 3 для визуализации графа
зависимостей пакетов Alpine Linux (формат apk). Готовые менеджеры пакетов и
библиотеки для получения зависимостей не используются.

## Общее описание

Приложение получает имя пакета и источник данных (URL репозитория или файл
тестового репозитория), строит граф зависимостей и визуализирует его.
Текущий этап: **Этап 1 — минимальный прототип с конфигурацией**.
Реализован разбор и проверка параметров командной строки; при запуске
приложение выводит все параметры в формате «ключ = значение».

## Функции и настройки

Источник настроек — параметры командной строки:

| Параметр | Описание |
|----------|----------|
| `--package ИМЯ` | имя анализируемого пакета (латинские буквы, цифры и символы `. _ + -`, первый символ — буква или цифра) |
| `--repo ИСТОЧНИК` | URL репозитория (`http://` или `https://`) или, в тестовом режиме, путь к файлу тестового репозитория |
| `--test-mode` | режим тестового репозитория: `--repo` задаёт путь к существующему файлу |
| `--ascii-tree` | вывод зависимостей в формате ASCII-дерева |
| `-h`, `--help` | справка |

Параметры `--package` и `--repo` обязательны. Проверяются все параметры:
отсутствующие или пустые значения, недопустимое имя пакета, некорректный
URL, отсутствующий файл или каталог вместо файла в тестовом режиме. Такие
ошибки выводятся сообщением `Ошибка: ...` (код завершения 1). Неизвестные
опции, параметр без значения и флаг со значением (`--ascii-tree=yes`)
обнаруживает разборщик параметров (код завершения 2).

## Сборка проекта

Сборка не требуется: проект написан на Python 3 (интерпретируемый язык),
сторонние библиотеки не нужны, устанавливать зависимости не надо.

## Запуск

Требуется Python 3.9 или новее.

- Windows: `run.bat [параметры]` (или `py src\main.py [параметры]`)
- Linux/macOS: `sh run.sh [параметры]` (или `python3 src/main.py ...`)

Скрипт ОС для проверки этапа 1 (успешные запуски и все виды ошибок):

    scripts\test_stage1.bat

## Запуск тестов

Из корня проекта:

    py -m unittest discover -s tests -t .

На Linux/macOS вместо `py` используйте `python3`.

## Примеры использования

    py src\main.py --package nginx --repo https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64 --ascii-tree

    Параметры запуска:
      package    = nginx
      repo       = https://dl-cdn.alpinelinux.org/alpine/v3.20/main/x86_64
      test_mode  = False
      ascii_tree = True

Тестовый режим:

    py src\main.py --package A --repo data\graph_simple.txt --test-mode

Пример ошибки:

    py src\main.py --package nginx --repo not-a-url
    Ошибка: некорректный URL репозитория: 'not-a-url'

## Структура проекта

- `src/main.py` — точка входа
- `src/config.py` — параметры командной строки, проверка и вывод
- `data/` — файлы тестовых репозиториев
- `scripts/` — скрипты ОС для проверки этапов
- `tests/` — модульные тесты
- `run.bat`, `run.sh` — скрипты запуска
